Indian Health Insurance Claims — Regression

23CSE301 Machine Learning Capstone Project

This project uses supervised machine learning regression algorithms to predict the total health-insurance claim amount for an Indian health-insurance policyholder.

Problem Statement

Given a policyholder's demographic profile, lifestyle and health-risk indicators, policy details, and hospitalisation information, predict:

total_claim_amount — the rupee value of the claim filed against the policy.

₹151,678

The notebook converts these values into numeric form before analysis.

3. Outlier Handling

The target distribution contains a small number of very large claims.

Instead of deleting these observations, the notebook winsorises the target at the 99th percentile.

The motivation is to retain genuine high-cost hospitalisations while reducing the disproportionate effect of extreme claims on squared-error metrics such as RMSE and R².

4. Feature Engineering

Two important engineered features are created:

total_hospital_days

Combines ICU days and ward/hospital stay duration into a single measure of admission burden.

The notebook reports a correlation of approximately 0.63 with the target, compared with:

length_of_stay: approximately 0.57

icu_days: approximately 0.54

icu_ratio

Represents the proportion of an admission spent in ICU.

This helps distinguish admissions with similar total durations but different levels of critical care.

5. Data Leakage Control

The following columns are excluded because they are arithmetic components of the target:

hospital_bill_amount
pre_hospitalization_expense
post_hospitalization_expense
non_payable_items
deductible_amount
co_pay_amount

The notebook verifies the relationship:

total_claim_amount ≈
hospital_bill_amount
+ pre_hospitalization_expense
+ post_hospitalization_expense
- non_payable_items
- deductible_amount
- co_pay_amount

Including these columns would allow a model to reconstruct the target rather than learn meaningful predictive relationships.

Identifier-like columns are also excluded, including:

policy_id
customer_name
hospital_name
aadhaar_masked
pincode

This demonstrates the importance of keeping the target scale appropriate for SVR's loss function.

12. Feature Importance

A Random Forest model is used for tree-based feature-importance analysis.

The notebook finds that the engineered:

total_hospital_days

is the dominant feature, carrying approximately half of the total feature importance.

The three hospital_tier dummy variables together contribute approximately 0.18 importance.

This supports the EDA observation that admission duration and hospital pricing structure are important drivers of claim size.

13. Key Findings

The dataset required substantial data cleaning before modelling, particularly because the target contained currency-formatted strings and income used mixed units.

Six billing-component columns were removed to prevent target leakage.

length_of_stay and icu_days showed strong relationships with claim amount.

The engineered total_hospital_days feature captured more signal than either duration variable individually.

hospital_tier produced a substantial difference in claim distributions.

Gradient Boosting achieved a test R² of approximately 0.765 in the initial model comparison.

Hyperparameter tuning produced only small changes for the two models selected for tuning.

ElasticNet improved substantially after tuning, demonstrating that default hyperparameters can strongly affect model performance.

Residual analysis indicates that prediction errors become larger for higher-cost claims.
